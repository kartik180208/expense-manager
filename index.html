      Data structures used How it works

      Linked list

      Stores every expense as a node. New expenses go at the tail, and delete works by ID.

      Add O(n) · Delete O(n) · Traverse O(n)
      Stack

      Remembers each add and delete, so Undo reverses the latest action first (LIFO).

      Push O(1) · Pop O(1)
      Queue

      Pending bills wait in order, and Pay next serves the oldest bill first (FIFO).

      Enqueue O(1) · Dequeue O(1)
      Hash table

      Groups spending by category using chaining, and feeds the pie chart.

      Insert O(1) avg · Lookup O(1) avg
      Sorting and search

      Sort by amount or date, and search by scanning the list for a keyword.

      Sort O(n log n) · Search O(n)
